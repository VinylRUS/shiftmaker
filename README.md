# ShiftMaker — график смен сотрудников

**ShiftMaker** — веб-приложение в виде Excel-подобной таблицы: сотрудники × дни
недели, смены с временем (включая ночные через полночь), дежурства без времени
и примечания. Перетаскивание смен мышью, копирование и очистка недель, тёмная
тема.

## Доступ к редактированию

По умолчанию приложение открывается в **режиме просмотра** — расписание видит
каждый, у кого есть ссылка. Чтобы редактировать, нажмите **«Войти по коду»**
в шапке и введите код администратора (переменная окружения `ADMIN_CODE`).

- Код проверяется **на сервере**: все операции записи в API требуют
  httpOnly-cookie с подписью HMAC, которая выдаётся только после верного кода.
- Вход запоминается на 30 дней (пока не нажмёте «Выйти» или не смените код).
- Смена `ADMIN_CODE` на сервере мгновенно «гасит» все ранее выданные входы.
- Ссылка `?mode=edit` сразу открывает окно ввода кода — удобно для админа.

## Стек

- **Next.js 16** (App Router, TypeScript) + React 19
- **Tailwind CSS 4** + shadcn/ui
- **Prisma + SQLite**
- **dnd-kit** — drag & drop смен

## Локальный запуск

```bash
npm install          # зависимости
cp .env.example .env # путь к базе (опционально, есть умолчание db/custom.db)
npm run db:generate  # Prisma-клиент
npm run db:init      # создать БД + демо-данные при первом запуске
npm run dev          # http://localhost:3000
```

Продакшен-сборка локально:

```bash
npm run build
npm start            # PORT=3000, слушает 0.0.0.0
```

## Полезные команды

| Команда            | Что делает                                             |
|--------------------|--------------------------------------------------------|
| `npm run dev`      | dev-сервер с hot reload                                 |
| `npm run build`    | продакшен-сборка                                        |
| `npm start`        | продакшен-сервер (`PORT`, хост `0.0.0.0`)               |
| `npm run db:init`  | `prisma db push` + демо-данные, если база создаётся впервые |
| `npm run db:seed`  | перезаписать базу демо-данными                          |
| `npm run lint`     | ESLint                                                  |

## Переменные окружения

| Переменная     | По умолчанию      | Смысл                                       |
|----------------|-------------------|---------------------------------------------|
| `DATABASE_URL` | `file:../db/custom.db` | Путь к SQLite-базе (в Docker — `/app/data/schedule.db`) |
| `ADMIN_CODE`   | `1234`            | Код входа в режим редактирования — **обязательно смените в продакшене** |
| `SEED_DEMO`    | `1`               | `0` — не заливать демо-данные при первом старте |
| `PORT`         | `3000`            | Порт продакшен-сервера (задаёт Bothost)     |

```
src/app/api/…            # REST API (access, employees, shifts, health)
src/components/schedule/ # WeekTable, ShiftChip, ShiftDialog, AccessDialog, EmployeeManager…
src/lib/                 # access (код+cookie), палитра, даты, типы, db

```
